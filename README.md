## Установка и запуск

1. Клонируйте репозиторий
   bash
   git clone https://github.com/Ksenia-netizen/my-react-app2.git

Перейдите в папку проекта

bash
cd my-react-app2
Установите зависимости

bash
npm install
Запустите локальный сервер разработки

bash
npm start
Приложение откроется по адресу http://localhost:3000

Доступные скрипты
Скрипт	Описание
npm start	Запуск в режиме разработки
npm run build	Сборка оптимизированной версии в папку build
npm test	Запуск тестов (если добавлены)
npm run eject	Извлечение конфигурации Webpack (только при необходимости)
